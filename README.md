# Proyecto_TostadorCaf-
El siguiente repositorio de la plataforma, describirá toda la parte de desarrollo a nivel codigo como a nivel de Hardware, todo integrado con el proposito de crear un espacio organizado donde se agrupe lo visto en clase con las funcionalidades de este proyecto.
El proyecto consiste en el diseño e implementación de una tostadora de café automatizada de pequeña escala, con capacidad aproximada de 250 a 300 gramos por lote. El sistema estará basado en un microcontrolador ESP32 y permitirá automatizar y supervisar las principales etapas del proceso de tostado mediante la adquisición de temperatura, el control del sistema de calentamiento, el control del movimiento del café, la temporización del proceso y la ejecución de una etapa de enfriamiento.

El usuario podrá seleccionar un perfil básico de tueste, iniciar, pausar, reanudar o finalizar el proceso y consultar su estado mediante una interfaz local. El sistema contará además con mecanismos de seguridad para detectar condiciones anormales, como sobretemperatura o fallos en la adquisición de temperatura, llevando los actuadores a una condición segura.

La implementación estará orientada a un sistema embebido de pequeña escala y permitirá organizar sus funciones en tareas independientes bajo un sistema operativo de tiempo real, priorizando el control, la supervisión y la seguridad del proceso.
