# Proyecto_TostadorCaf-
El siguiente repositorio de la plataforma, describirá toda la parte de desarrollo a nivel codigo como a nivel de Hardware, todo integrado con el proposito de crear un espacio organizado donde se agrupe lo visto en clase con las funcionalidades de este proyecto.
Tostador automático de café de bajo costo: se propone el desarrollo de un prototipo de tostador de café para lotes aproximados de 250 g. El sistema utilizará un ESP32 como unidad de procesamiento, una termocupla tipo K con módulo MAX6675 para medir la temperatura del proceso, una resistencia eléctrica como elemento calefactor y un motorreductor de 12 V para mantener el tambor en rotación. El objetivo es obtener un tostado más uniforme mediante el monitoreo y control de temperatura, manteniendo una arquitectura sencilla y reduciendo el número de componentes para disminuir el costo del prototipo. Se contemplan inicialmente tres niveles de tostado: claro, medio y oscuro.
